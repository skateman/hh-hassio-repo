# ACME Courier

A lightweight Home Assistant add-on that obtains Let's Encrypt certificates
through Namecheap DNS-01 challenges and deploys the resulting PEM files to local
directories or remote SSH targets. ACME, Namecheap, proxy, certificate, and
deployment settings are configured directly through the add-on Configuration
tab.

See [DOCS.md](DOCS.md) for configuration and migration details.
